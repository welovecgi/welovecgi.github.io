# Camp Gan Israel Cherry Hill website

Plain HTML site, hosted free on GitHub Pages.

- Pages: the .html files in this folder. The top menu is in js/site.js (NAV).
- Styles: css/style.css. Forms: js/forms.js (sends to the camp's Google Sheet).
- Photos: images/ (gallery photos in images/2026/). Calendars: calendars/ (PDF + preview picture).
